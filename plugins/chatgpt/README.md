# Invoke Human for ChatGPT and Codex

This package asks one person for a decision, a worksheet, or a form, then returns the answer to ChatGPT or Codex. The person writes on an Apple device or answers in a browser. The MCP server is https://invokehumantool.com/mcp. Authentication is OAuth with dynamic client registration, and the scope is handoffs. The plugin does not delete handoffs, read another account, or move money.

It is published by Abhirup Ghosh under the MIT license. Support is https://invokehumantool.com/support. Privacy is https://invokehumantool.com/privacy and terms are https://invokehumantool.com/terms.

Zip this directory so `plugin.json` is at the root of the archive when you submit it to the OpenAI plugin directory. Do not put a password or an agent key in the zip. Reviewer credentials belong in the private review field of the submission form.
