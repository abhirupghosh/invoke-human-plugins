# Invoke Human for Grok

Grok does not load a plugin manifest from disk. `connector.json` records the arguments for the remote server: the name Invoke Human, the URL https://invokehumantool.com/mcp, and OAuth with the scope handoffs. In chat, add that MCP server and leave the headers empty.

The listing is under Abhirup Ghosh, not a company. The license for this package is MIT. Support is https://invokehumantool.com/support. Privacy is https://invokehumantool.com/privacy and terms are https://invokehumantool.com/terms.

The marketplace form asks for a name, a website, an MCP URL or a public GitHub repository, a description, and testing instructions. Point the form at the remote URL. Testing instructions should name the directory reviewer account. Do not put the password in this repository.
