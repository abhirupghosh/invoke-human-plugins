# Shared Invoke Human assets

This folder holds the command text and the Ping logo that the client packages copy. It is not a directory listing by itself. Ping is the coral stick figure from `assets/brand`: plate `#FBF8F2`, head `#FF7A6E`, ink `#161616`. `logo.svg` is the square icon. `logo-512.png` and `logo-256.png` are the rasters. `logo-64.svg` and `logo-64.png` thicken the connector strokes for a tiny slot such as the ChatGPT composer icon. The SVG includes a background plate so a form that wants a square image can use it.
