# Invoke Human for Cursor

Invoke Human lets Cursor ask one person and wait for the answer. The question can be an approval, a worksheet, a sketch, or a form. The person answers on an Apple device or in a browser. This plugin points Cursor at https://invokehumantool.com/mcp and adds a skill, two commands, and a rule. OAuth uses the scope handoffs. Do not put a bearer token in `mcp.json`.

Abhirup Ghosh publishes the plugin under the MIT license. Support is https://invokehumantool.com/support. Privacy is https://invokehumantool.com/privacy and terms are https://invokehumantool.com/terms.

Copy this folder to `~/.cursor/plugins/local/invoke-human` and reload Cursor, or install it from the public marketplace repository `abhirupghosh/invoke-human-plugins` after that repo is published. The deeplink installs the MCP server only. This folder also installs the skill.
