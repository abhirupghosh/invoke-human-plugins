# Invoke Human

When a decision, approval, worksheet, sketch, or form needs the person, use the invoke-human skill and the MCP server named `invoke-human` (`https://invokehumantool.com/mcp`). Decide yourself when the task already answers it, a documented default is safe, or you can undo the choice.

Send once. Call `wait_for_handoff` with the id. `status: pending` is a successful tool call. Grade a form from `answers` and a worksheet from the PDF.

This file is the project guidance to merge into a repo Codex works in. The skill text is the generated copy at `skills/invoke-human/SKILL.md` in this folder. Do not paste an `answer_url` into the chat.
