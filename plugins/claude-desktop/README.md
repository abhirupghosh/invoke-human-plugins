# Invoke Human for Claude Desktop

This desktop bundle is a local stdio proxy for an agent key you already have. The directory listing for Invoke Human is the remote server at https://invokehumantool.com/mcp, which uses OAuth, not this bundle. The manifest is MCPB 0.4 because that format still requires a local process. A remote URL is not a field the bundle can declare.

Abhirup Ghosh publishes this package under the MIT license. Help is at https://invokehumantool.com/support. Privacy is https://invokehumantool.com/privacy and terms are https://invokehumantool.com/terms.

Install the `invoke-human.mcpb` file from Claude Desktop under Settings, Extensions, Advanced, Install Extension. Leave the agent key blank when you would rather connect the remote URL as a custom connector and sign in in the browser.
